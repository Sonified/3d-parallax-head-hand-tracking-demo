Shared vs Independent Frame Upload

Simulates the real pipeline: multiple workers each needing the same camera frame.
Tests whether uploading once (SharedArrayBuffer) beats uploading N times independently.


Scenario: Simulates tracking 2 hands + 1 face per frame.
Independent: 3 workers each get a VideoFrame, each uploads to their own GPU, each does letterbox.
Shared: 1 frame server uploads + letterboxes once, writes to SharedArrayBuffer, 3 consumers read via Atomics.

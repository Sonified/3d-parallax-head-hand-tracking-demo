Pipeline Architecture Shootout v2

Render loop decoupled from camera. Render runs at display refresh (120Hz ProMotion).
Inference runs async. Measures effective render FPS, inference throughput, and result freshness.


Key change: Render loop uses requestAnimationFrame (120fps on ProMotion), NOT tied to camera frames (30fps).

1. Serial: Render waits for inference. Locked to inference speed. (Baseline worst case)
2. Fire-and-forget: Kick off inference on new camera frames. Render always runs, uses latest result. Never waits.
3. Double-buffer fire-and-forget: Two workers. Kick off inference on every camera frame. Overlap inference. Never wait.
4. Kalman skip: Infer every 2nd camera frame. Predict on skips. Render at full display rate always.
5. Fire-and-forget + Kalman interp: Infer async, render at 120fps with Kalman interpolation between measurements.

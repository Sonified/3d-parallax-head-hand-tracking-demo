👻 Data Injection with Your Friendly Neighborhood Ghost

Author: Robert Alexander






What this demonstrates:


Ghost metadata can be injected into a simulation that is already running, not just at initialization. The fluid flows for 10 ticks with no ghost data present. At tick 10, ghost values are injected into 5 cells of the active simulation. The simulation then continues for 50 more ticks. The injected metadata is conserved exactly (0.00% drift) throughout the remaining simulation, and the physics (mass conservation, momentum) is unaffected by the mid-stream injection. This proves that Fluid Ghost Encoding is composable with live simulations: metadata can be written to any cell at any time without disrupting the physics or losing conservation guarantees.


Baseline: In conventional game engines, adding new metadata to a running simulation requires allocating new storage, initializing advection state, and synchronizing with the physics tick. In Fluid Ghost Encoding, injection is a single moment-space write that takes effect immediately. The ghost modes accept the data, the physics ignores it (guaranteed by orthogonality), and the conservation protocol maintains it from that point forward. No allocation, no initialization, no synchronization. This test verifies that the protocol works not just from cold start but from any point in a running simulation.
